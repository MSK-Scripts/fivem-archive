# msk_blackmoney
Blackmoney Washing Script

## Description
* Skillcheck to open the Door and get teleported into the MLO
* Admin Commands to ignore Skillchecks
* Turn on the Machines with an Animation
* Configured Jobs will get a Notification
* MSK Blackout integration *(Cops won't get a Dispatch if Blackout is toggled)*

## Commands
* msk_blackmoney *(Ignores Skillcheck at the Door)*
* msk_blackmoney_skip *(Ignores second Skillcheck inside the MLO)*

## Requirements
* [ESX Legacy](https://github.com/esx-framework/esx_core)
* [msk_core](https://github.com/MSK-Scripts/msk_core)
* [ox_lib](https://github.com/overextended/ox_lib)
